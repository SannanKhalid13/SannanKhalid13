## 🔬 Research & Dissertation

### MSc Dissertation: From-Scratch JPEG Codec (ITU-T T.81)
Implemented a complete JPEG encoder and decoder in Python directly from the ITU-T T.81
specification — no image libraries, no reference implementation. Includes:
- Colour space conversion (RGB → YCrCb)
- Block DCT, quantization tables, zig-zag ordering
- Run-length encoding + Huffman entropy coding
- LZW compressor
- Quality metrics: PSNR, SSIM, MSE, MAE
- Validated against libjpeg across 40 test images

📖 **[View the code →](https://github.com/SannanKhalid13/python-jpeg-encoder-decoder)**
